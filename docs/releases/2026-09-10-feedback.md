# 10 September feedback release

Sources: CRM 10.09.zip and more new stuff 10.09 feedback on crm.zip.

## Implemented

- Joint applicants receive their own application/signing links, messages and communication history. Shared stages advance together; individual reviews and signatures remain separate.
- Onboarding drafts survive email previews and document refreshes. Previews show the actual email. Message channels can be selected, failed delivery is reported, and follow-ups retain onboarding access.
- Document review decisions save together, require a rejection reason and support revised categories/decisions before agreement issue. Credit checks retain entered values.
- Agreements include the supplied clauses, consistent fonts/letterhead, signatures in the main/appendix/receipt spaces, and a signature certificate. Existing agreements can be resent without erasing signatures; reissue warns clearly. Links and signing progress are visible, and a confirmed no-handover path is supported.
- Public forms require city/town, format money, preserve each joint applicant’s details/preferences, separate the later application sections and clear validation messages on success.
- Inventory supports mobile capture and desktop PDF upload, tenancy selection/date, individual tenant review links, photo comments, extra photos and signing. Issued originals are locked. Staff can read responses and copy review links if delivery needs recovery.
- Login/sidebar/settings, profile photo/accent, addresses, dates, property features, active-tenant notes and calendar labels updated. Removal offers archive where records must be retained; bulk removal cannot bypass contract protection.
- Maintenance requires allocation before progress and accepts multiple attachments. Public reporting uses the requested branding and emergency wording.
- Flemo supports per-user ChatGPT sign-in, scoped CRM evidence, PDF text/OCR, payment history and latest SMS. It provides read-only answers; bank balances are not inferred.
- Landlord registration supports individual/joint/company details, beneficial owners, addresses and protected ownership/compliance uploads to landlord enquiries.
- Multiple guarantors can be recorded. Office data corrections/import and named test cleanup have prepared, identity-checked scripts and off-host backups.
- FreeAgent setup guide and three interactive mobile design proposals are included in docs/office.
